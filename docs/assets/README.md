# Recursos visuais

Os diagramas de funcionamento e segurança são mantidos como Mermaid no
[README principal](../../README.md), sem cópias de imagens geradas.

As capturas reais ficam em [`screenshots/`](screenshots/README.md). O guia dessa
pasta registra as três imagens disponíveis (prévia, Dark Beach e Vampire), os dados
de exemplo e os cuidados com privacidade. A aba Temas e o conflito detectado ainda
aguardam capturas. Os caminhos pessoais foram ocultados com autorização do autor.

Não é necessário adicionar SVGs ou imagens raster para representar os fluxos já
descritos em Mermaid. Recursos novos devem ter uma finalidade clara e permanecer leves.

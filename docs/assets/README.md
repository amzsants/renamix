# Capturas reais

Esta pasta receberá capturas do aplicativo em execução. Nenhuma imagem fictícia foi criada.

| Arquivo previsto | Conteúdo |
| --- | --- |
| `renamix-original.png` | Aba Renomear, com três arquivos de exemplo e prévia. |
| `themes.png` | Aba Temas com as oito opções. |
| `dark-beach.png` | Prévia no Dark Beach refinado. |
| `vampire.png` | Prévia no Vampire refinado. |

Use uma pasta descartável com nomes fictícios (ex.: `IMG_001.jpg`, `IMG_002.jpg`,
`IMG_003.jpg`) e uma substituição `IMG_` → `Foto_`. Não exiba documentos, caminhos
pessoais, relatórios reais ou outras janelas. Escolha manualmente cada tema e capture
somente a janela. Não é necessário alterar a resolução do sistema.

Confira a legibilidade de nomes, status e botões antes de salvar. Informe sistema,
resolução e escala usados na legenda. Prefira PNG e mantenha a mesma dimensão entre
as capturas. Não use imagens do artista, capas, logotipos ou montagens que se passem
pelo aplicativo. As imagens só devem ser incorporadas ao README após existirem e
serem revisadas; os nomes acima são uma convenção, não arquivos de imagem vazios.
